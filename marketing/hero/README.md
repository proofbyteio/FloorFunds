# FloorFunds marketing hero

Single-viewport landing hero for FloorFunds (casino cage cash advance).

## Open locally

```bash
# from this folder
python3 -m http.server 8765 --bind 127.0.0.1
# then open http://127.0.0.1:8765/
```

Or open `index.html` directly in a browser (video needs network for the CloudFront loop).

## Design notes

Built from the MotionSites [Agent Wave](https://motionsites.ai/?prompt=agent-wave) free design: liquid-metal nav, bottom-anchored hero copy, three capability stats, Particle Wave background loop. Brand tokens adapted to FloorFunds dark + gold CTAs.
